# Jadeborn: The Ember Road

Play: https://kitanox12-prog.github.io/jadeborn/

On iPhone: open the link in Safari → Share → **Add to Home Screen**, then launch Jadeborn from its icon and turn the phone sideways.
On a computer: open the link in Chrome, Edge or Firefox. WASD to move, 1–6 abilities, Q to swap heroes; "Players: 2" on the title screen for same-keyboard co-op.

Source lives in `src/`; run `./build.sh` to rebuild the site.
